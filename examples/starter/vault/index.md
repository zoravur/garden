This garden is a folder of markdown files. Every link opens a note beside the one you're reading, so you can follow a thought sideways without losing your place.

Good first stops: [[Evergreen notes]], [[ideas/Backlinks|why backlinks matter]], and [[How this site is built]].

!!! tip "Writing a note"
    Make a file, link it with `[[Its Title]]` from anywhere, and rebuild. Links work by file name, so you can move notes between folders without breaking them.
